# Kasper - Training Web Project

This is a personal training project built as part of my learning journey with **Elzero Web School**. The project is a fully responsive and modern website created using **HTML** and **CSS**, following clean design principles and real-world layout practices.

## 🔨 Technologies Used

- HTML5  
- CSS3 (Flexbox + Grid + Media Queries)  
- Normalize.css  
- Font Awesome  
- Google Fonts

## 📄 Pages & Sections

The project is a single-page layout that includes the following major sections:

- **Header** – A responsive top navigation bar with logo and links.
- **Landing Section** – Introductory content with background image and text overlay.
- **Services** – A set of service boxes each with an icon and description.
- **Design Features** – A split layout with image and list of UI/UX features.
- **Portfolio** – Image gallery section showcasing sample work with hover effects.
- **Video Section** – A full-width video background with an overlay and CTA.
- **About Us** – Brief information about the team/company.
- **Stats** – Animated stats for metrics like projects and emails sent.
- **Skills & Testimonials** – Progress bars to reflect skills and client feedback.
- **Pricing Plans** – Multiple pricing options with visual styling.
- **Subscribe Section** – Newsletter subscription form.
- **Contact Section** – Contact form and company location details.
- **Footer** – Social media icons and branding.

## 🎯 Purpose

The purpose of this project is to apply what I’ve learned from:

- ✅ HTML Course  
- ✅ CSS Course  

It demonstrates my understanding of responsive layout, clean and semantic HTML, structured CSS, and how to build a professional-looking landing page.
